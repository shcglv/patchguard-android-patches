In Morphe Manager:

```text

```

Manager resolves the repository to the root `patches-bundle.json` on `main`, reads
the release metadata and downloads `patches-1.0.0.mpp`.

## Limitations

- Static-only: no target APK was downloaded, no app was patched or launched.
- Compatibility is declared for Ozon 19.31.0, not runtime-verified.
- The release is unsigned; signing is a recommended follow-up.
- The three patches are ported from Jl4cTuk/morphe-patches (GPL-3.0); attribution
  is preserved in the source headers.
- If Morphe Manager's patcher is older than 2.5.0, it will reject the bundle as
  needing a newer Morphe build.
