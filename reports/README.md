# Reports

Generated reports for security, compatibility, dependency and update reviews.

- `security/` — per-patch static security summaries.
- `compatibility/` — static compatibility assessments and declared targets.
- `dependencies/` — SBOM and CVE summaries.
- `updates/` — source change detection and re-audit queues.

Reports are generated from audit records and catalog data; they are not independent sources of truth. Do not edit generated reports by hand.
